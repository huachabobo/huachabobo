## 01 / Lecia AgentOS / 旗舰项目

**Lecia AgentOS 是一套 governance-first、自托管的 AgentOS control plane，让 AI 工作在真正运行起来以后仍然可操作、可检查、可恢复。**

**Lecia AgentOS is a governance-first, self-hosted AgentOS control plane built to keep AI work operable, inspectable, and recoverable after the demo becomes a system.**

它不是给聊天框再套一层 UI，而是把 Provider、任务队列、approval、memory、snapshot、adapter 与 operator evidence 收进一条诚实的执行链路。

It is not another chat wrapper. It brings providers, task queues, approvals, memory, snapshots, adapters, and operator evidence into one honest execution loop.

## 02 / CodeLife Lab / 数字生命研究

**CodeLife Lab 研究的是运行在 LifeVM 中的非 LLM 数字生命：可执行 genome、能量账户、受控 action ports、繁殖、突变、死亡与谱系。**

**CodeLife Lab studies non-LLM digital life running inside LifeVM: executable genomes, energy accounts, bounded action ports, reproduction, mutation, death, and lineage.**

LLM 与 Codex 可以管理世界、帮助开发，但不充当生命体的大脑。研究目标不是把结果讲得像 AGI，而是建立可以重复、反驳和审计的弱数字生命证据。

LLMs and Codex may manage the world and assist development, but they are not the organism's brain. The goal is not to narrate AGI into existence; it is to build weak digital-life evidence that can be reproduced, challenged, and audited.

## 04 / Working Principles / 工作原则

**让运行时说真话。** 状态、失败、恢复和证据应该来自真实执行，而不是漂亮文案。<br />
**Make the runtime tell the truth.** State, failure, recovery, and evidence should come from real execution, not presentation copy.

**让治理成为默认值。** Approval、audit、rollback 和最小权限不应该等到事故以后才出现。<br />
**Make governance the default.** Approval, audit, rollback, and least privilege should exist before the incident.

**把文档当作产品界面。** 好文档不仅解释系统，也约束系统不会悄悄变成另一种东西。<br />
**Treat docs as a product surface.** Good documentation explains the system and keeps it from quietly becoming something else.
